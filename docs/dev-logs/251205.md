## 2139
Interestingly, it is possible to initialize specific variables of a structure
by indicating the variable prefixed with a dot as was suggested in
[GNU's intro to C](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Designated-Inits.html).

```c
struct point { int x; int y; };
struct point foo = { .y = 42 };
```

I wonder about the logic behind this. I guess it follows in the same manner
as C's methods (I don't believe that this is the correct term, as this is
a Java term) where sub-functions/features may be accessed by `function.feature`,
and, in this case, the function `point` is already being referenced so `.y` is
just the assumption that represents `function.feature`.

## 2252
When an instruction is described "indirect" it means that the instruction uses
a register as a pointer, rather than using the register’s value directly.

So for `LD (BC), A`, instead of operating on the value in register BC, it is
instead operated on the memory pointed to by BC. This is why parentheses are
used.

It is identical to the C language's:

```c
*(BC) = A;
```
