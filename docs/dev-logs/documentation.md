The LR35902's use of a 16-bit stack pointer in an 8-bit CPU is a design choice
within consideration of the CPU's efficiency and simplicity. By combining
8-bit registers into 16-bit pairs and using a 16-bit stack pointer, the CPU
can perform a wide range of operations with a compact instruction set, making
it well-suited for the resource-constrained environment of the original Game
Boy.
